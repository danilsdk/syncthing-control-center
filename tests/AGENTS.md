# Проверки

Пиши проверки значимого поведения и отказов. Общие fixtures принадлежат A;
фикстуры одного модуля размещай внутри его разрешённой зоны.
Unit и contract не используют личные файлы и реальные рабочие узлы.
Реальный E2E использует отдельный стенд, ограниченные ожидания и повторные
наблюдения; фиксированный sleep не доказывает синхронизацию.
Результаты harness, mock-проверок и реального стенда записывай отдельно.
Проверки самого harness размещаются в `scripts/tests/`, владелец B.
