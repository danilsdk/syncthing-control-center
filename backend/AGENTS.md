# Backend

Общие модели, миграции, настройки и точка сборки принадлежат A / playerboom.
Пакеты scheduling, reconciliation, analytics и их роутеры принадлежат B / danilsdk.
Точные исключения смотри в `.harness/project.json` и карточке задачи.

- Предметная логика не делает прямые HTTP-вызовы Syncthing, а обращается к адаптеру.
- Передавай время и внешние зависимости так, чтобы отказные сценарии можно было
  проверить без настоящего Syncthing. Реальные проверки проводи отдельно.
- Не открывай новые управляющие маршруты без общей зависимости авторизации.
- Проверки backend включаются при появлении Python-кода/pyproject. A0 задаёт
  dev-extra с pytest/Ruff и актуализирует `.harness/checks/backend.json`.
  Установи окружение через команду `setup`.
