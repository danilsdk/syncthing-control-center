# Общая схема — A / playerboom

Одна последовательность Alembic и один владелец миграций. Учитывай потребителей B.
Для смены поля/ограничения опиши влияние на контракт и порядок перехода.
Проверяй миграцию на пустой БД и обновление существующего тестового состояния.
Уникальность папки определяется экземпляром и Syncthing Folder ID.
Один активный rule на папку обеспечивается согласованным ограничением, а не только UI.
Реальные ключи/пароли не помещаются в seed, fixtures и открытые поля моделей.
