# Документы и доказательства

Общие продуктовые документы и контракт ведёт A. Документы harness, задания,
промпты и шаблоны ведёт B. Части отчёта, design и журналы — в папке своей роли.
Запланированное поведение не описывается как уже работающее.
Каждой завершённой задаче соответствует собственный журнал с реальными
проверками, ссылками и ограничениями. Не редактируй общий журнал параллельно.
Не включай в Git разговоры с секретами и личными данными; достаточно требований,
решений агента, проверок, правок человека и ссылки на результат.
