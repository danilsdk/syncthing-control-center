## Дефект и решение

[GitHub run 40374446691](https://github.com/danilsdk/syncthing-control-center/actions/runs/40374446691)
на Ubuntu 24.04 / Python 3.12.14 прошёл lint/format/контракт и выполнил 456 offline:
455 passed / 1 failed / 0 errors/skips. Старый тест
test_deadline_covers_slow_headers_and_a_slow_body[body] получил AttributeError
в HTTPResponse._close_conn: response.fp уже стал None до вызова fp.close().
SQL и core не запускались. Оба cleanup прошли; private папка удалена.

Watchdog вызывает connection.close из другого потока одновременно с read1.
HTTPConnection.close меняет response.fp, а HTTPResponse не обеспечивает такую
синхронизацию. План исправления: прерывать только нижележащий socket через
shutdown; HTTPConnection/HTTPResponse закрывает сам поток запроса в finally.
Исключение AttributeError не перехватывается для маскировки причины.

## Проверки

между EOF и изменением response.fp, затем deadline либо owner close. Timer/часы
управляемые; чтение и HTTPResponse настоящие. Никаких sleep для доказательства
гонки и автоматического retry тестов нет. Старые ожидания срока не изменяются.

NoneType.close (a4-ci/a8-red.xml вне Git). После переноса connection.close в
finally потока запроса все 29 transport cases passed. Ruff сначала нашёл одну
строку нового теста длиной 101; строка разделена, check и format затем passed.
