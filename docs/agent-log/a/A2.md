## Решения

- A2.2: один локально создаваемый администратор; подписанная сессия 8 часов,
  HttpOnly/SameSite/Secure, Origin/CSRF, ограничение входов; stdlib scrypt/HMAC
  без новой зависимости. Детали и первичные источники приведены в плане.
- A2.3: регистрация только через allowlist connection_ref после проверки источника,
  закрепление Device ID и атомарная запись узла/папок. Базовой схемы достаточно;
  миграция предварительно не планируется.
- Списки читают кеш, детальное чтение обновляет только выбранный enabled-узел
  по TTL. Ошибки сохраняют последние значения и времена, неизвестное не становится
  успехом. После регистрации A2 не меняет канонический checkpoint/курсор A3.
- Пара desired_paused/active_rule_id берётся только из авторитетного вычислителя
  B1; при активном правиле и отсутствии интеграции — безопасный отказ, не выдуманная цель.
- A2.4: настоящий API с частной PostgreSQL и двумя узлами, включая T-01/T-12,
  отказы и передачу следующим модулям. Scheduler/UI/коллектор не реализуются в A2.
