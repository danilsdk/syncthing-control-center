## Результат и решения

[Открыть прототип](../../design/b/prototype/index.html) · [Спецификация и план переноса](../../design/b/prototype/design.md)

Хранящиеся в ветке HTML, CSS и JavaScript работают из файлов. Для передачи в основной каталог проекта собран автономный `прототип/index.html` со встроенными шрифтами, стилями и скриптами. Рядом находится та же версия `design.md`. Исходный референс предварительно открыт в Chrome, рассмотрены его снимок, четыре JPG и семь экранов B3. Доступные операции сверены с актуальным frontend из main и контрактом D-03/D-04/D-05.

Сценарий разбора проходит от фильтрованного списка к конкретной папке, версии правила и попытке. Для возврата сохраняются URL выборки, положение и ключ строки. Предпросмотр формы показывает ночную часть окна в следующем дне. Локальная модель отдельно меняет расписание и статус попытки. Второй набор данных позволяет попробовать ручное возобновление, два одноимённых Folder ID и ненулевые метрики.
