## Получившееся поведение

Добавлен React + TypeScript + Vite интерфейс с экранами входа, обзора, папок,
правил, истории и аналитики. Все экраны различают загрузку, пустые данные,
ошибку, неизвестное и устаревшее наблюдение. Правило можно создать и включить
или отключить с передачей `expected_version`; ручное возобновление доступно только
для папки без активного правила и отображает ожидание подтверждения.

Провайдер данных разделён: `VITE_DATA_MODE=mock` включает локальные fixtures и
явный баннер демонстрационного режима, а обычная сборка использует same-origin
`/api`, cookie-сессию и CSRF-токен только в памяти. В frontend нет Syncthing URL,
API-ключей или физических путей. Vite proxy направляет `/api` и `/health` на
локальный backend.
