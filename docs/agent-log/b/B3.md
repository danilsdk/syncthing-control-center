## Получившееся поведение

React/TypeScript/Vite UI: вход с восстановлением сессии, обзор, папки, CRUD правил,
история команд с серверными страницами и UTC-фильтрами, отдельная заготовка аналитики.
Ошибка аналитики или отдельного модуля не скрывает остальные ресурсы.
Неизвестные/устаревшие наблюдения, пустые данные, загрузка и ошибки различаются.
Показаны фактическая и желаемая пауза, отдельные времена конфигурации/runtime.
Ручное возобновление сохраняет idempotency key при потере ответа, а подтверждение
читает отдельным GET. `pending` и HTTP 202 не отображаются как applied.

Используется same-origin `/api`, HttpOnly cookie и CSRF в памяти. При 401 из чтения
или изменения workspace удаляется вместе с данными. Обновление вкладки восстанавливает
сессию через `/auth/me`; неуспешный logout виден и не выдаётся за подтверждённый.
Syncthing URL, ключи и физические пути в браузер не передаются. Сборка API не содержит
demo-fixtures/тестовых canary. Mock включается только отдельной командой/режимом,
имеет постоянный баннер и не заменяет ошибку настоящего API.
