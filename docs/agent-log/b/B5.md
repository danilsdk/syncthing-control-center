## Решения и изменения

В исходных черновиках B5 отсутствовали реальные снимки, отдельный журнал и проведённая репетиция. Регистрация демо-узлов ссылалась на руководство, где указаны псевдонимы без команды регистрации. Для сценария добавлены конкретные действия в панели и точные проверки. Выбраны три окна с запасом по времени и все дни недели, чтобы повтор около полуночи сохранил смысл каждого шага.

На принятой сборке версия 1 подтвердила паузу, версия 2 — возобновление. После остановки `demo-a` регистрировались ошибки проверки, `demo-b` оставался доступен. На недоступном узле сохранили версии 3 и 4. После запуска тот же worker отправил команду по версии 4. Пауза подтверждена в 10:27:52 UTC, новое наблюдение папки получено в 10:28:07 UTC. Отправок по версии 3 — ноль. Удаление правила и отдельная подтверждённая ручная попытка вернули папку в исходное состояние. [Протокол штатного Compose](../../report/parts/b/evidence/compose-rehearsal.json)

Проверка штатного Compose установила HTTP 404 на `GET /api/analytics/summary` после входа. Временно подключённый маршрут использовал ту же БД и окно репетиции: 4/4 подтверждённых команд и 14/16 успешных проверок API, для пустого периода «Нет данных». Временное подключение API было ограничено тестовым проектом и завершилось его очисткой. [Протокол дополнительной проверки](../../report/parts/b/evidence/analytics-preview.json)
