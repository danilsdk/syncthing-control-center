## Получившееся поведение

`calculate_desired_paused` принимает явный aware момент, переводит его в IANA
timezone и возвращает `false` внутри полуоткрытого окна, `true` вне окна и `null`
для отсутствующего/выключенного правила. Окна через полночь продолжаются от дня
начала, включая переход воскресенье → понедельник; повторившийся DST-час даёт
одинаковый результат, пропущенный час не воспроизводится.

Добавлен сервис правил и экспортируемый `router` для `/api/rules`: список с
пагинацией и фильтром папки, создание, чтение, versioned PATCH и DELETE.
Запись, изменение и удаление сериализуются общей folder advisory lock A0.
Проверяется наличие папки, активность узла при переходе правила в enabled,
единственное активное правило и optimistic version; старые версии дают
`version_conflict`, второй active rule — `active_rule_conflict`.

### Исправление по review PR #12 — 2026-10-29

Напарник воспроизвёл гонку PostgreSQL `READ COMMITTED`: после `COUNT(*)` и
перед чтением страницы другая транзакция могла вставить правило, после чего
`RulePage` получал `total=0` и один item и возвращал HTTP 500. `list_rules`
теперь делает одну согласованную выборку с детерминированной сортировкой,
вычисляет `total` и срез страницы из одного результата; пустая страница за
концом также сохраняет полный total. Добавлены интеграционные регрессии для
межтранзакционной вставки и пустого offset.
