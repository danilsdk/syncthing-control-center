## Получившееся поведение

Экран аналитики показывает долю подтверждённых команд и долю успешных проверок
API по периоду, узлу и источнику команд. Вместе с итогами видны дневные значения
UTC, ошибки, неизвестные, отменённые и ожидающие подтверждения попытки.
Пустой знаменатель отображается как «Нет данных».

## Решения и изменения

- Маршрут `/api/analytics/summary` использует общие DTO и защищённую сборку A.
- PostgreSQL возвращает агрегаты одним снимком. Источник ограничивает команды,
  фильтр узла действует на команды и проверки. Снимки папок исключены.
- Окно `[from, to)` и группировка по UTC проверены с настройкой сеанса
  PostgreSQL `Pacific/Honolulu`.
- Браузерный сценарий с реальным стендом принимает UUID отдельной
  демонстрационной папки. Он создаёт правило и проверяет подтверждение паузы,
  появление попытки в истории и аналитике. В конце папка возобновляется.
