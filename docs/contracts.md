# Контракт модулей — начальный черновик

**Статус: draft.** Реализация API и моделей ещё отсутствует. Этот файл обозначает
точку согласования A0/B0 и не утверждает неизвестные маршруты или схемы.
Владелец — A / playerboom, потребитель и reviewer — B / danilsdk.

## Уже заданные ограничения

- Управление адресует папку определённого управляемого экземпляра.
- Один активный rule на папку, один исполнитель правил в MVP.
- История — UTC, расписания — timezone IANA.
- HTTP-успех и подтверждённое применение — отдельные факты.
- После восстановления рассчитывается актуальное состояние.
- Неизвестные состояния и пропуски наблюдений не дают ложного успеха.
- API Syncthing доступен через адаптер; его ключи не передаются frontend.
