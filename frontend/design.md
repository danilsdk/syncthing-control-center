# Дизайн Syncthing Control Center

Рабочий интерфейс открывается с «Обзора». Администратор видит наблюдение папки, её узел, действующее расписание и последние записи. Запросы выполняет существующий React-клиент через API SCC. Визуальным образцом служит [утверждённый прототип](https://github.com/danilsdk/syncthing-control-center/tree/b732edd9f75b210b8b77fa6f2137a0222b69ebaa/docs/design/b/prototype).

## Как устроены экраны

| Адрес | Что здесь сделать |
| --- | --- |
| `#/login?next=…` | Войти с учётной записью администратора и продолжить с запрошенного экрана. |
| `#/overview` | Посмотреть выбранную папку и состояние её узла, открыть папку, правило или запись. При нескольких папках показана закреплённая либо первая в списке с явной подписью. Последние записи относятся ко всем папкам. |
| `#/folders` | Найти папку по названию, исходному Folder ID или узлу. Клавиша `/` переводит фокус в поиск. Поиск и фильтры узла и свежести отражаются в адресе. |
| `#/folders/:id` | Сверить конфигурацию и время отдельного наблюдения синхронизации. Закрепить папку на обзоре, открыть её правило или отфильтрованную историю. При подтверждённой паузе доступно ручное возобновление с отдельным чтением результата. |
| `#/folders/:id/appearance` | Поменять имя для отображения, выбрать один из восьми значков или ввести свой символ. Предпросмотр обновляется по мере ввода. Имена и значки сохраняются в браузере под внутренним ID. |
| `#/rules`, `#/rules/:id` | Выбрать правило, проверить версию и последнюю попытку, изменить границы окна на недельной шкале. Справа видны даты трёх ближайших окон и настроенное местное время. Если переход часового пояса пропускает всё окно, эта дата исключается. |
| `#/rules/new?folder=…`, `#/rules/:id/edit` | Создать или изменить расписание с днями начала, часами и зоной IANA. При удалении требуется подтверждение, которое можно закрыть клавишей Escape. |
| `#/history/commands`, `#/history/events` | Разобрать попытки и события по периоду UTC, узлу и папке. Для попыток есть фильтр результата. Фильтры и смещение страницы передаются на сервер. Старый адрес `#/history` открывает команды. |
| `#/history/commands/:id`, `#/history/events/:id` | Открыть одну запись по прямой ссылке. У попытки показаны цель, отправка, проверка, состояние и код результата. Событие содержит свой тип и сведения о пропуске, если он зарегистрирован. |
| `#/analytics` | Выбрать 24 часа, 7 или 30 дней либо собственный период и узел. Обе доли и их знаменатели приходят из одного ответа summary. При нулевом знаменателе видна надпись «Нет данных». |

## Маршрут администратора

1. В «Папках» выбрать «Без свежих данных» и нужный узел. Открыть строку папки.
2. Нажать «Открыть правило», затем «Открыть попытку». Подбор попытки использует внутренний ID папки и ID правила. Если на первой серверной странице попыток совпадения нет, клиент читает следующую.
3. Сверить версию, цель, фактическую паузу и время проверки. Ответ на отправку команды означает, что идентификатор попытки получен. Результат определяется отдельным серверным чтением. События файлов живут в своём журнале.
4. Нажать «К списку папок». Восстановятся исходный адрес с фильтрами, положение страницы и фокус строки. Для перехода из списка в оформление фокус возвращается к кнопке настройки конкретной папки.

## Материалы и взаимодействие

- Графитовый фон, тёплый белый текст и оранжевый акцент применяются ко всем разделам и входу. Логотип, локальные начертания Inter и иллюстрация папки перенесены из утверждённого «Обзора». Лицензия Inter включена в сборочные исходники.
- Перемещаемая плашка навигации имеет равномерную заливку белым с непрозрачностью 9%, кромку 12% и размытие 6 px. Значок дома и подпись «Обзор» видны вместе. Переход положения занимает 260 мс, ширины — 220 мс. На узком экране подписи располагаются под значками.
- Передняя стенка иллюстрированной папки частично скрывает листы. У детальной карточки собственный значок, заголовок и отдельные панели наблюдений и расписания.
- На недельной шкале мышь и касание меняют границы с шагом 15 минут. Стрелки дают шаг 15 минут, Shift со стрелкой — час. Поля времени позволяют ввести минуты точно. Ночное окно продолжается в строке следующего дня, включая переход с воскресенья на понедельник. Изменение применяется ко всем выбранным дням. «Отменить» возвращает сохранённое состояние.
- «Сохранить окно» отправляет одну версионированную операцию. При конфликте черновик остаётся доступным для сравнения с актуальной версией. Удаление и ручное возобновление имеют собственные действия и результаты.
- Наведение, нажатие и клавиатурный фокус различимы. В режиме сокращённого движения анимация переходов отключается.

## Данные и границы интеграции

В обычной сборке работает `ApiProvider`. Сеанс использует HttpOnly cookie, запись — CSRF, редактирование — `expected_version`, ручная команда — ключ идемпотентности. Журнал и наблюдения показывают время UTC, шкала использует часовой пояс правила. Подробности команды читаются через `GET /api/executions/:id`. Для событий текущий контракт предлагает только список, поэтому клиент ищет нужную запись постранично и прекращает поиск при уходе с экрана.

Для экрана аналитики нужен `GET /api/analytics/summary` из B4. Если маршрут недоступен, интерфейс показывает ошибку и кнопку повторного чтения. Остальные экраны продолжают работать. Для локального просмотра с демонстрационным провайдером предусмотрена отдельная команда `npm run dev:mock`. Исходные настройки имени и значка можно редактировать в обоих режимах.

Инструкция по сборке, переменным окружения и проксированию запросов находится в [руководстве по frontend](../docs/design/b/ui.md).
