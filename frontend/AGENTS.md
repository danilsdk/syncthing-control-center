# Frontend — B / danilsdk

Backend API и JSON-примеры — источник формата данных. Syncthing API-ключи и прямой
доступ к Syncthing не используются в браузере. Неизвестное/устаревшее состояние
показывается отдельно от здорового. Предусматривай загрузку, пустые данные и ошибки.
Mock-режим отделён от настоящего API и не подтверждает готовность всей системы.

Harness ожидает npm lock-файл и команды `lint`, `test:ci`, `build`.
Стек выбирается в B0. При выборе другого менеджера B изменяет
`.harness/checks/frontend.json` в B3 и фиксирует воспроизводимую установку.
API-контракт не меняется ради удобства одного экрана.
