# Выполнение задачи SCC

Используй для реализации карточки этого репозитория. Процесс и команды описаны
в `docs/harness.md`; путь разрешения — `.harness/tasks/<ID>.json`.

- До изменений прочитай карточку, её текстовое описание, относящиеся вложенные
  `AGENTS.md` и текущий контракт. Определи готовые зависимости и доступную работу
  на test doubles; незавершённый контракт не выдавай за принятый.
- Работай в worktree и ветке карточки. `start <ID>` создаёт отдельную папку из
  опубликованной исходной ветки. При начале в уже подготовленной папке используй
  `snapshot <ID>` один раз до работы, если снимка ещё нет.
- Реализуй критерии готовности, сохраняя чужие изменения. Контракт меняет его
  владелец в отдельной задаче, если прямое поручение не разрешило иной порядок.
- Проверь `scope --task <ID>`, затем `validate --task <ID>`. Отдельно выполни
  сценарии карточки, включая необходимые реальные интеграционные испытания.
- Заполни свой файл журнала по `docs/templates/agent-result.md`: результаты,
  команды, фактические доказательства, ограничения и точный следующий шаг.
- После успешных проверок допустим commit собственных файлов в рамках задачи.
  Публикация и merge следуют существующему поручению человека; навык сам по себе
  не даёт разрешения писать в GitHub или разворачивать сервис.
- Перед началом и передачей задачи проверь готовые PR напарника по постоянному
  поручению AGENTS.md. Для их review/approval/merge используй `$scc-review` и
  отдельную рабочую папку; свой PR оставляй агенту напарника.

Для возобновления прочитай собственный журнал и актуальный diff, затем продолжай
с оставшегося шага. Не повторяй готовую работу из-за смены сессии.
